## New Features
- alert system updates: spawn rate is now modified by current alert level, missions that dont complete automatically (such as retrievals) will cause alerts to start spawning a bit faster than normal [0de226d]
- clientside version of the quest visibility checker (changes state based on the local client's completed quests, rather than the hosts) [2747f82]
- generic quest reward (doesnt actually do anything, just to add something there for completed quest-related checks) [96e9f88]
- shop levels can now be hidden/locked behind quest completion (when the level is the 2nd level and it has no items in the first level and this is true, it hides the upgrade button until the quest is completed, otherwise it will appear as locked) [a05b62a]
- implemented time calculation when traveling between regions (varies based on the distance between the regions) (closes #49) [8940f54]
- implemented some additional settings (visibility ranges for corpse/outlines, ads sens multi, and some various quality settings, not really sure what else to add in that front tbh) (closes #13) [f4fda46]
- added a little label nagging you to change your player color when your player color is default [2d7d3b7]
