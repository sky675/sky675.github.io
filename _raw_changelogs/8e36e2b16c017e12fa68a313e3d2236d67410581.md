## New Features
- bots can now flank (kinda), only giving this to melee rn, not entirely sure how well this works (it appears to? i dont really have a test level that works well with this, they get within strafe range too quickly), also add ability to shoot while chasing [c6ddaac]
- new ai type (camper) - once they get a target, they will immediately seek cover and sit there as long as possible (unused currently, just adding some simpler micro types) (closes #96) [0269380]
- new ai type (simple) - doesnt runaway/cover when reloading/item usage, can only chase or strafe (ditto, but will prob change low level gang to use this later) (closes #34) [35bf3c5]
- new ai type (runaway) - this one just directly runs away when it enters combat, shooting if it has los, when it leaves combat itll change its origin to its current position (so it doesnt return to where it was) (closes #35) [8c5e50c]
- new macro ai type (follower) - when it finds a patrol position, it'll search its group to try and find a non-follower in its group, for the first one it finds (typically should be the group leader, it is in hierarchy order it says) it will center that patrol position around that leader (closes #37) [f4654da]
- new macro ai type (defense) - when this one hears something, it will direct another member of its group to investigate it instead of it (it can also investigate it too if a bool is toggled or there is no valid members in its group to choose from) [6e597be]
- new macro ai type (hunter) - ai will pick a random valid target as its patrol position (closes #36), last normal ai type i had ideas for (there are others designed to work with events thatll be added later) [bccf937]
- new autoload effect target `show_hidden_descs`, when an event's main desc is empty, there is an alternate desc that can be used instead if the flag is true which will be added below the normal event descs [8a510e9]
- faction def now has a list of "alternate" subfactions, if something tries to generate a bot of a subfaction that doesnt exist and that subfaction type is in the alternate list, itll use the defined alternate for it [ce63185]
- add button to open up the overlay invite ui since apparently people actually use that? [f0022d4]
- free loadout container - after dying, you can interact with this, found in certain traders, to get a random free loadout. rn they all give the same stuff but what they give will get better for versions in later regions (will do that later), currently available in: smelmart, hara, and harland, also, added sell container to harland [75a544e]
