## New Features
- quests can now require another quest to be active/completed to be visible, and also can give a different set of rewards when accepting it [ec291f0]
- quest rewards can now be individually hidden from the reward list (plan to use this mostly for post quest notifys) [6b7150d]
- added a quest reward that displays a notify message when the reward is given [374a456]
- bot subfactions can now use another subfaction's clothing (and override/add onto it) [821c871]
- region levels can now use the previous level's pools/alert settings, rather than having its own (recursively, thisll be used to make extra rep levels simpler) [7318ce8]
- daemon will now go into a temporary cooldown when its defeated/unalerted, which will prevent it from finding the user for a few ticks (closes #132) [54163e9]
- sandbox saves now start with all the regions set to the level after another region is unlocked (for every region rn this is also the max level), with it defaulting to just the max level if no such level exists in the region [5466d11]

## New Content
- added a hacker subfac for gang, plus a hack event to spawn a hacker squad as the daemon, also made kage have a chance to not have a network [f54268e]
